# ТЗ на разработку веб-интерфейса AI-сервиса оценки качества денситометрии

## 1. Цель

Разработать веб-интерфейс сервиса на основе ИИ для автоматической оценки качества денситометрических исследований.

Сервис должен принимать обезличенные медицинские исследования в формате DICOM, передавать их на AI-анализ и отображать пользователю выявленные ошибки и итоговую оценку качества исследования.

## 2. Основной функционал

Веб-интерфейс должен обеспечивать:

- авторизацию пользователей;
- загрузку DICOM-файлов и ZIP-архивов с исследованиями;
- автоматическую проверку и обезличивание данных;
- хранение и отображение списка исследований;
- просмотр DICOM-снимков;
- запуск AI-анализа;
- отображение статуса обработки;
- отображение результата анализа;
- классификацию выявленных ошибок;
- визуальное отображение найденных нарушений непосредственно на снимке;
- возможность экспертной проверки результата AI;
- сохранение экспертной оценки и разметки.

## 3. Список исследований

В таблице отображать: ID исследования; дату; тип/область исследования; статус обработки; итоговую оценку; количество выявленных ошибок; статус экспертной проверки.

Предусмотреть поиск и фильтрацию.

## 4. Карточка исследования

**Общая информация**: ID; дата; тип исследования; статус.

**DICOM Viewer**: просмотр снимков; масштабирование; перемещение; настройка яркости/контрастности; отображение AI-разметки.

**Результат AI**: итоговая оценка качества; список выявленных нарушений; категория ошибки; степень критичности; уверенность алгоритма.

## 5. Экспертная оценка

Эксперт должен иметь возможность: подтвердить ошибку AI; отклонить ошибку; изменить категорию ошибки; добавить собственную ошибку; выделить область на снимке; добавить комментарий.

Результаты экспертной оценки должны сохраняться для последующего анализа и возможного дообучения алгоритма.

## 6. Классификация нарушений

Предусмотреть возможность классификации ошибок, например: неправильное позиционирование; неполная/неправильная область исследования; артефакты; низкое качество изображения; ошибки ROI/сегментации; технические ошибки DICOM.

Справочник нарушений должен быть редактируемым администратором.

## 7. Роли

Минимум две роли:

**Администратор** — управление пользователями; просмотр всех исследований; управление справочником ошибок; просмотр статистики.

**Эксперт** — загрузка исследований; просмотр снимков; просмотр AI-анализа; экспертная разметка и корректировка результатов.

## 8. Архитектура

Интерфейс должен взаимодействовать с AI через API:

`Web-интерфейс → Backend → AI-модуль → результат анализа`

Архитектура должна позволять в дальнейшем менять или обновлять AI-модель без существенной переработки веб-интерфейса.

## 9. Безопасность

- работу с обезличенными медицинскими данными;
- разграничение прав доступа;
- защищённое соединение;
- журналирование действий пользователей;
- защиту DICOM-файлов и результатов анализа.

## 10. Результат разработки

На выходе должен быть готовый веб-продукт, позволяющий пройти полный сценарий:

Загрузить DICOM → запустить AI-анализ → получить оценку → увидеть ошибки на снимке → провести экспертную проверку → сохранить результат.

# Исходная постановка задачи (хакатон)

## Актуальность

Автоматизированный анализ медицинских изображений денситометрии представляет значительный клинический интерес в контексте качества получения изображений. Интеграция алгоритмов искусственного интеллекта позволяет объективизировать оценку ключевых параметров разметки. Автоматизированный анализ повышает качество полученных изображений точность исследования, без повышения нагрузки на врача-рентгенолога.

## Описание задачи

Разработать сервис искусственного интеллекта, осуществляющий автоматизированную оценку качества денситометрических изображений и их разметки.

## Ресурсы

Обезличенные медицинские изображения денситометрии. Обезличенные медицинские изображения денситометрии с экспертной разметкой.

## Описание итогового продукта

Программное обеспечение (ПО), получающее на вход рентгеновское денситометрическое исследование в формате DICOM, и оценивающее качество выполнения исследования по стандартным критериям, а также корректность разметки анатомических структур на изображениях. В результате работы ПО должны быть определены качественные исследования, а для исследований с нарушениями качества должен быть определен тип нарушения.
