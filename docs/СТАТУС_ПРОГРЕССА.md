**Шаг 1 (анатомическая область).** `BodyPartExamined` в датасете всегда
пустой, суффиксов в закрытом тесте не будет → классификатор чисто по
пикселям. Признак — билатеральная симметрия, но теперь по **двум** осям
зеркалирования (доработано 2026-09-23): центр кадра И центроид масс
объекта, берётся максимум. Раньше (одна ось — центр кадра) при сильном
смещении объекта от центра (>~9% ширины, найдено на синтетике с
shift_x=70px) классификатор путал позвоночник с бедром. С двумя осями
разрыв между классами вырос с 0.20/0.125 до **0.20/0.457** (максимум у
бедра / минимум у позвоночника на всех надёжных данных) — порог поднят
0.25→0.30. Известный ранее сложный случай (реальное исследование с
`axis_misaligned=True`, раньше ошибочно уходило в «бедро») теперь
классифицируется верно. → `backend/ai_module/heuristics.py::classify_anatomical_region`.

**Шаг 2 (калибровка геометрии).** `backend/ai_module/calibration.py` —

**Шаг 3 (маппинг нарушений).** `backend/ai_module/submission_mapping.py` —

  на первых именах перед полной распаковкой, не доверять вслепую.
