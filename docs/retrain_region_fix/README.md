# Переобучение после исправления определителя области (29.09.2026, вечер)

Эксперимент, **не принятый в боевую версию**. После исправления определителя
области (27 снимков бедра больше не попадают в «позвоночник») переобучены
скореры позвоночника и CNN (кросс-валидация 5 фолдов, те же разбиения по
исследованиям, тот же seed) и пересчитаны метрики всего решения.

| Файл | Что |
|---|---|
| `pipeline_cv.json` | метрики всего решения; порог CNN по внешним OOF (вложенная CV остановлена после 2 из 5 внешних фолдов — не успевала к сдаче) |
| `model_vs_heuristic_ci.json` | ROC-AUC CNN и правил по каждому нарушению с 95 % ДИ |
| `spine_scorers_cv.json` | кросс-валидация скореров позвоночника |

Итог: ROC-AUC всего решения 0.67 [0.58–0.76], F1 0.36 [0.21–0.51] (порог CNN
0.5 — F1 0.41) против 0.73 / 0.50 в боевой версии. Причина — разброс обучения
CNN, а не добавленные снимки: **на тех же 261 снимках бедра** ROC-AUC OOF
укладки — 0.70 против 0.85 у прежнего прогона; на 20 добавленных — 0.69.
То есть при почти тех же данных оценка CNN колеблется в диапазоне 0.70–0.85.

Решение (Ринат, 29.09): в боевой версии остаются прежние веса и метрики,
исправленный определитель области работает на инференсе. Стабилизация CNN
(несколько seed, ансамбль, повторные прогоны CV) и переобучение с верной
областью — на этап доработки. Подробно — `docs/КАЧЕСТВО_РЕШЕНИЯ.md`.
